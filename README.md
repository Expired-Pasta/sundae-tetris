# 🍲 순대국 테트리스 (Sundae-guk Tetris)

순대국 재료 아이콘으로 만든 웹 테트리스입니다. 설치 없이 브라우저에서 바로 플레이할 수 있습니다.

## ▶️ 플레이

GitHub Pages 주소를 그대로 열면 됩니다: `https://<사용자이름>.github.io/sundae-tetris/`

> **지원**: PC 크롬/엣지/파이어폭스/사파리, 모바일 브라우저 (카카오톡 링크 공유 가능)

## 🎮 조작

| PC | 모바일 |
|---|---|
| ← → : 이동 | 하단 버튼 / 좌우 스와이프 |
| ↑ : 회전 | 🔄 버튼 / 게임판 탭 |
| ↓ : 한 칸 내림 | ▼ 버튼 / 아래 스와이프 |
| Space : 즉시 낙하 | ⏬ 버튼 |
| P : 일시정지 | ⏸ 버튼 |

## 🍽️ 재료 블록

7가지 테트로미노마다 재료 아이콘이 그려집니다:
국물그릇 / 뚝배기 / 고기 / 상추 / 밥공기 / 고추 / 마늘

## 📁 파일

- `index.html` — 게임 전체 (HTML/CSS/JS 단일 파일, 빌드 불필요)
